## How each row was derived

Roll-ups from the probe grid, so the glyph is reproducible rather than a judgement:

| Row | Probes | Rule |

| Durable execution | `C1`, `C3`, `B9` | best of |
| Mailbox | `F5`, `F6` | best of |
| Checkpoint/resume | `C7`, `E8` | best of |
| HITL | `C11`, `G5` | best of |
| Sandbox | `K1`, `K5`, `K9` | best of |
| Agent registry | `D5`, `D6` | best of |
| Shared memory | `H3`, `H10` | best of |
| Governance | `I8`, `J10` | best of |
| A2A / MCP | `O5` prose | hand-verified per teardown |

**A2A and MCP were graded by hand.** A keyword pass over `O5` produced four false
positives, because Google AX, Letta, LangGraph and Agent Control all write "**No**
MCP, A2A or ACP" — the negation runs across a list and a naive match reads each
protocol as present. Corrected against each teardown's protocol section.

`?` appears only for AWS AgentCore (a client SDK over managed services) and MS Agent
Framework (a targeted pass over a 75MB repo). Those are genuinely *not inspectable*
rather than absent; recording them as `○` would have overstated nine gaps.

## What the map shows at a glance

**Table stakes** — every project has these, so they differentiate nothing:
durable execution (13/13), HITL (12/13 at ● or ◐), checkpoint/resume (11/13).

**Single-source capabilities** — one project each, which is where the design leans:
mailbox (AG2 only), content-derived pinning (MAF only), memory service with
provenance (ADK only), durable `Approval` (HumanLayer only), `observe`/`steer`
(Agent Control only), workload identity + Cedar (AgentCore only).

**The mailbox row is the study's most important line.** Eight of the projects in
your original table show `○`, and after seven consecutive absences I had drafted an
ADR rewrite abandoning durable agent messaging entirely. AG2 implements it, better
than my strawman did. Had the map stopped at eight projects, the conclusion would
have been wrong — which is the argument for the five you omitted.

## Caveats

1. **A roll-up hides disagreement.** Cloudflare and Google AX both score ● on
   durable execution and their mechanisms are opposite (ambient DO storage vs a
   folded event log). Use the matrix and the teardowns for design decisions; use this
   map for orientation.
2. **● is not an endorsement.** Google AX scores ● on durable execution and sandbox
   while shipping *zero* authentication. LangGraph scores ● on checkpoint/resume and
   silently loses work when the graph changes.
3. **A blank cell in "Our decision" is deliberate.** The evidence for each row is in
   `decisions/` and `synthesis/build-reuse-map.md`; the choice is yours to record.
